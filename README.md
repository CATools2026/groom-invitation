Saturday 21 November 2026 at 8:30 AM · Gonagama Reception Hall, Hanhamunawa. Dark maroon theme with the second-day wedding couple.

## GitHub Pages

In Settings → Pages, choose Deploy from a branch, main, /(root), and Save.

## Update details and album

Edit invitation.js to update the event details. Replace album/01.jpg, album/02.jpg and album/03.jpg to update the photographs without changing the invitation link. To add more photos, edit album/photos.js.

The invitation is a static website. Keep index.html and all folders at the repository root. No build step is needed. Music starts when the envelope opens; the small speaker icon mutes or unmutes it.
